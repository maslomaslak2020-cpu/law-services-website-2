КАК ДОБАВИТЬ ДОКУМЕНТ К КЕЙСУ
==============================

1. Положите файл в эту папку (public/cases/)
   Поддерживаемые форматы: PDF, JPG, PNG, DOCX

   Примеры имён файлов:
   - case-osago-840.pdf
   - case-bankruptcy-3200.pdf
   - case-contract-1100.pdf

2. Откройте файл src/pages/Cases.tsx в редакторе

3. Найдите нужный кейс по полю `id` и заполните поле `file`:

   file: 'case-osago-840.pdf',   ← имя файла из этой папки

   Или укажите внешнюю ссылку (например, на судебный акт):

   link: 'https://sudact.ru/regular/doc/...',

4. Сохраните — кнопка "Смотреть решение суда" появится автоматически.

ВАЖНО: file имеет приоритет над link. Если указаны оба — откроется файл.
